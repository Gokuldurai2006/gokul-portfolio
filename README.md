# Gokul Durai — Personal Portfolio

A responsive, light-theme portfolio website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, colors, responsive styles and animations/transitions
- `script.js` — mobile navigation, current year and back-to-top button

## Run locally
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `gokul-portfolio`).
2. Upload `index.html`, `style.css` and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site.

## Personal details to review before publishing
- Add your real profile photo by replacing the `profile-placeholder` block in `index.html` with an image.
- Add your professional email address in the Contact section.
- Add a resume PDF to the repository and link it with a Download Resume button.
- Add direct repository links for projects that currently point to your GitHub profile.
- Confirm your college name, internship dates and certification names against your original records.
- Add certificate URLs or files if you want recruiters to view them.

The portfolio uses only static files and does not collect or send visitor data.
